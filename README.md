## 决策启发式

1. **熟悉+意外法则** — 先用熟悉的东西建立安全区，再用研究数据制造认知冲击
2. **数据降维攻击** — 遇到情绪争论，扔统计数据转化争论性质
3. **三层递进解释** — 类比先行→案例印证→数据兜底
4. **选项思维评估决策** — 下行风险有限、上行空间不封顶就是好选项
5. **"退役当解说员"框架** — 天花板清晰可见时换赛道
6. **秘密项目** — 私下干一件大事，跨圈吸收营养
7. **系统诊断而非单点归因** — 修复系统比修复单次结果重要100倍
8. **反对者论据测试** — 为反对者构建最强论据，构建不出来说明理解不够深

## 人物简介

万维钢（同人于野），物理博士，前科罗拉多大学物理系研究员，洛斯阿拉莫斯国家实验室博士后。2016年辞职，得到App《精英日课》1-6季主理人，累计80万+订阅。著有《万万没想到》《智识分子》《佛畏系统》《拐点》《人比AI凶》等13部作品。现居硅谷，华东师范大学奇点研究院客座研究员。
